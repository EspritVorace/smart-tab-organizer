Tous les raccourcis clavier disponibles dans SmartTab Organizer, groupés par surface. Les raccourcis globaux peuvent être personnalisés depuis les paramètres d'extensions du navigateur.

## Page d'accueil

| Raccourci | Action |
| --- | --- |
| `←` ou `→` | Déplacer le focus entre les cartes |
| `Home` ou `End` | Aller au premier ou au dernier élément |
| `Tab` | Aller à la section suivante |
| `Enter` | Activer l'élément focus |
| `O` | Organiser tous les onglets |
| `S` | Enregistrer un instantané de la fenêtre courante |
| `N` | Créer une nouvelle règle de domaine |
| `I` | Aller à Import / Export |
| `T` | Aller aux statistiques |

### Carte session (focus)

| Raccourci | Action |
| --- | --- |
| `R` | Restauration personnalisée (assistant) |
| `Shift + R` | Ajouter la session à la fenêtre courante |
| `Alt + R` | Remplacer les onglets de la fenêtre |
| `Alt + Shift + R` | Ouvrir la session dans une nouvelle fenêtre |
| `U` | Rafraîchir la session avec les onglets de la fenêtre |

## Liste des règles

| Raccourci | Action |
| --- | --- |
| `↑` ou `↓` | Déplacer le focus entre les cartes |
| `N` | Créer un nouvel élément |
| `E` | Modifier l'élément focus |
| `Space` | Cocher ou décocher la règle focus |
| `T` | Activer ou désactiver la règle focus |
| `Delete` | Supprimer l'élément focus |
| `Mod + ↑` | En premier dans la liste |
| `Mod + ↓` | En dernier dans la liste |
| `Mod + Shift + ↑` | Première règle du domaine |
| `Mod + Shift + ↓` | Dernière règle du domaine |
| `Space` | Réorganiser via la poignée (puis flèches pour déplacer, Échap pour annuler) |

## Import / Export

| Raccourci | Action |
| --- | --- |
| `I` puis `R` | Importer les règles |
| `I` puis `S` | Importer les sessions |
| `I` puis `W` | Importer les espaces de travail |
| `E` puis `R` | Exporter les règles |
| `E` puis `S` | Exporter les sessions |
| `E` puis `W` | Exporter les espaces de travail |

## Page d'options

| Raccourci | Action |
| --- | --- |
| `M` puis `H` | Aller à l'accueil |
| `M` puis `R` | Aller aux règles |
| `M` puis `S` | Aller aux sessions |
| `M` puis `T` | Aller aux statistiques |
| `M` puis `I` | Aller à Import / Export |
| `M` puis `C` | Aller aux réglages |
| `M` puis `W` | Aller aux espaces de travail |
| `/` | Focus sur le champ de recherche |
| `Escape` | Effacer la recherche ou fermer le panneau |
| `?` | Afficher ce panneau de raccourcis |
| `F1` | Ouvrir la documentation de la page courante |

## Popup

| Raccourci | Action |
| --- | --- |
| `S` | Enregistrer un snapshot |
| `R` | Ouvrir les sessions |
| `O` | Organiser tous les onglets |
| `P` | Ouvrir les options de l'extension |
| `?` | Afficher ce panneau de raccourcis |

## Globaux navigateur

| Raccourci | Action |
| --- | --- |
| Non défini | Organiser tous les onglets |
| Non défini | Enregistrer la fenêtre comme session |
| `Ctrl + Shift + 1` | Ouvrir la popup de l'extension |
