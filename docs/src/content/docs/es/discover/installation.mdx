<Aside type="tip" title="En resumen">
- Disponible en el Chrome Web Store y en Firefox Add-ons.
- Cuatro permisos solicitados, todos locales (tabs, storage, notifications, scripting).
- Build local posible con `pnpm install && pnpm build` (o `pnpm build:firefox`).
</Aside>

## Instalar desde una tienda

<Tabs>
  <TabItem label="Chrome / Edge / Brave">
[SmartTab Organizer en el Chrome Web Store](https://chromewebstore.google.com/detail/smarttab-organizer/ijnpdkkcbmfikocmboibffjgbohhlmah). Compatible con todos los navegadores basados en Chromium (Chrome, Edge, Brave, Vivaldi, Arc, Opera).

<Steps>
1. Haz clic en **Añadir a Chrome**.
2. Acepta los permisos en el cuadro de diálogo del navegador.
3. Ancla el icono a la barra de herramientas desde el menú **Extensiones** para acceder rápidamente.
</Steps>
  </TabItem>
  <TabItem label="Firefox">
[SmartTab Organizer en Firefox Add-ons](https://addons.mozilla.org/firefox/addon/smarttab-organizer/).

<Steps>
1. Haz clic en **Añadir a Firefox**.
2. Acepta los permisos en el cuadro de diálogo.
3. El icono se ancla automáticamente a la barra de herramientas.
</Steps>
  </TabItem>
</Tabs>

## Permisos solicitados

La extensión solicita cuatro permisos, todos ellos utilizados exclusivamente en local. Ninguno autoriza una comunicación de red.

| Permiso | Para qué sirve |
|---|---|
| `tabs` | Leer las URL y los títulos de las pestañas para poder agruparlas y detectar duplicados. |
| `storage` | Persistir tus reglas, sesiones y ajustes en `browser.storage.local`. |
| `notifications` | Mostrar las notificaciones de agrupación y deduplicación, con el botón **Deshacer**. |
| `scripting` | Inyectar el content script que captura los clics centrales y los clics derechos sobre los enlaces, para disparar la agrupación. |

<Aside type="caution">
La extensión **no** solicita permisos de host extendidos ni `webRequest`. No puede inspeccionar el tráfico de red ni lee jamás el contenido de las páginas más allá de los enlaces en los que haces clic.
</Aside>

## Instalar en local desde el código fuente

Para desarrollar o probar una versión no publicada:

<Tabs>
  <TabItem label="Chrome / Chromium">

```bash
git clone https://github.com/EspritVorace/smart-tab-organizer.git
cd smart-tab-organizer
pnpm install
pnpm build
```

<Steps>
1. Abre `chrome://extensions` en Chrome.
2. Activa el modo desarrollador arriba a la derecha.
3. Haz clic en **Cargar extensión sin empaquetar** y selecciona la carpeta `.output/chrome-mv3/`.
</Steps>
  </TabItem>
  <TabItem label="Firefox">

```bash
git clone https://github.com/EspritVorace/smart-tab-organizer.git
cd smart-tab-organizer
pnpm install
pnpm build:firefox
```

<Steps>
1. Abre `about:debugging#/runtime/this-firefox`.
2. Haz clic en **Cargar un complemento temporal**.
3. Selecciona el archivo `.output/firefox-mv2/manifest.json`.
</Steps>

<Aside type="note">
Una instalación temporal en Firefox se pierde al cerrar el navegador. Para un uso permanente desde el código fuente, usa `pnpm zip:firefox` y firma el `.xpi`.
</Aside>
  </TabItem>
</Tabs>

## Primer arranque

Una vez instalada la extensión:

<Steps>
1. Haz clic en el icono de SmartTab Organizer en la barra de herramientas. El popup se abre vacío, sin ninguna regla ni sesión guardada.
2. Pulsa en **Opciones** para abrir la página completa. Si algunas de tus pestañas abiertas coinciden con un pack listo para usar, la pestaña **Inicio** muestra los packs coincidentes (con el número de pestañas afectadas por pack) y un botón **Importar y organizar**. En caso contrario, ofrece dos acciones genéricas: **Crear mi primera regla** o **Importar un pack**.
3. El análisis de los packs es totalmente local: tus pestañas abiertas se leen solo en el navegador, nada sale del equipo. Las sugerencias permanecen mientras no crees o importes una regla.
4. Tras la importación, un botón **Organizar ahora** ordena tus pestañas abiertas de inmediato. Consulta [Categorías y packs](/reference/categories-and-packs).
</Steps>
