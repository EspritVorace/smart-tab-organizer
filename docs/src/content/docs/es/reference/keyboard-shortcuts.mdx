Todos los atajos de teclado disponibles en SmartTab Organizer, agrupados por superficie. Los atajos globales se pueden personalizar desde la configuración de extensiones del navegador.

## Página de inicio

| Atajo | Acción |
| --- | --- |
| `←` o `→` | Mover el foco entre tarjetas |
| `Home` o `End` | Mover el foco al primer o último elemento |
| `Tab` | Mover el foco a la sección siguiente |
| `Enter` | Activar el elemento con foco |
| `O` | Organizar todas las pestañas |
| `S` | Guardar una instantánea de la ventana actual |
| `N` | Crear una nueva regla de dominio |
| `I` | Ir a Importar / Exportar |
| `T` | Ir a estadísticas |

### Tarjeta de sesión (con foco)

| Atajo | Acción |
| --- | --- |
| `R` | Restauración personalizada (asistente) |
| `Shift + R` | Añadir la sesión a la ventana actual |
| `Alt + R` | Reemplazar las pestañas de la ventana |
| `Alt + Shift + R` | Abrir la sesión en una nueva ventana |
| `U` | Actualizar la sesión con las pestañas de la ventana |
| `→` | Desplegar la lista de pestañas de la sesión |
| `←` | Plegar la lista de pestañas de la sesión |

## Lista de reglas

| Atajo | Acción |
| --- | --- |
| `↑` o `↓` | Mover el foco entre tarjetas |
| `N` | Crear nuevo elemento |
| `E` | Editar el elemento con foco |
| `Space` | Marcar o desmarcar la regla con foco |
| `T` | Activar o desactivar la regla con foco |
| `Delete` | Eliminar el elemento con foco |
| `Mod + ↑` | Mover al primero de la lista |
| `Mod + ↓` | Mover al último de la lista |
| `Mod + Shift + ↑` | Primera regla del dominio |
| `Mod + Shift + ↓` | Última regla del dominio |
| `Space` | Reordenar con el asa (luego flechas para mover, Esc para cancelar) |
| `→` | Desplegar el grupo enfocado |
| `←` | Plegar el grupo enfocado |
| `Space` | Marcar o desmarcar todo el grupo |

## Importar / Exportar

| Atajo | Acción |
| --- | --- |
| `I` luego `R` | Importar reglas |
| `I` luego `S` | Importar sesiones |
| `I` luego `W` | Importar espacios de trabajo |
| `E` luego `R` | Exportar reglas |
| `E` luego `S` | Exportar sesiones |
| `E` luego `W` | Exportar espacios de trabajo |

## Cambio de espacio

| Atajo | Acción |
| --- | --- |
| `W` luego `N` | Cambiar al espacio siguiente |
| `W` luego `P` | Cambiar al espacio anterior |
| `W` luego `L` | Cambiar al último espacio usado |

## Página de opciones

| Atajo | Acción |
| --- | --- |
| `M` luego `H` | Ir al inicio |
| `M` luego `R` | Ir a las reglas |
| `M` luego `S` | Ir a las sesiones |
| `M` luego `T` | Ir a las estadísticas |
| `M` luego `E` | Ir al catálogo de exploración |
| `M` luego `I` | Ir a Importar / Exportar |
| `M` luego `C` | Ir a los ajustes |
| `M` luego `W` | Ir a los espacios de trabajo |
| `/` | Enfocar el campo de búsqueda |
| `Escape` | Borrar la búsqueda o cerrar el panel |
| `?` | Mostrar este panel de atajos |
| `F1` | Abrir la documentación de la página actual |
