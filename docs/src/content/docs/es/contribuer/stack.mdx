SmartTab Organizer es una extensión de navegador multinavegador (Chromium MV3 y Firefox MV2), escrita íntegramente en TypeScript. Ninguna parte de la aplicación depende de un servidor o de un servicio de terceros: todo el código se ejecuta en el navegador.

## Pila aplicativa

| Capa | Tecnología |
|---|---|
| Build y empaquetado | [WXT](https://wxt.dev) (framework de extensiones multi-objetivo) |
| UI | React 19, [Radix Themes](https://www.radix-ui.com/themes) y [Radix Primitives](https://www.radix-ui.com/primitives) |
| Tipos y validación | TypeScript estricto, [Zod](https://zod.dev) para los esquemas en runtime |
| Tests unitarios | [Vitest](https://vitest.dev) y Testing Library |
| Tests E2E | [Playwright](https://playwright.dev) (Chrome MV3) |
| Storybook | Storybook 8 con addon-a11y y test-runner usando axe-core |
| Documentación | [Astro Starlight](https://starlight.astro.build) (este sitio) |
| Lint y formato | ESLint, Prettier |

## Navegadores objetivo

| Navegador | Manifest | Estado |
|---|---|---|
| Chrome | MV3 | Objetivo principal |
| Edge, Brave, Vivaldi, Arc, Opera (basados en Chromium) | MV3 | Compatible (mismo artefacto que Chrome) |
| Firefox | MV2 | Compatible (objetivos `pnpm build:firefox`, `pnpm zip:firefox`) |

Las API del navegador se acceden mediante `wxt/browser`, que normaliza las diferencias entre `chrome.*` y `browser.*`. La extensión usa un subconjunto presente en ambos: `browser.tabs`, `browser.tabGroups`, `browser.storage`, `browser.action` / `browser.browserAction`, `browser.notifications`, `browser.scripting`.

## Almacenamiento

| Backend | Contenido |
|---|---|
| `browser.storage.local` | Reglas de dominio, ajustes, sesiones (pinned, active, archived), espacios de trabajo, categorías, preferencias de UI (estado expandido, etc.) |
| `browser.storage.session` | Mapa perfil-ventana, borradores de sesión, guarda anti-reentrada de edición |

Sin cookies. Sin solicitudes de red más allá de las que hace el propio navegador.
