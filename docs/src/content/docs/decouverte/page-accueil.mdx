<Aside type="tip" title="En bref">
- La page d'accueil est le premier écran affiché à l'ouverture des Options.
- Tant qu'aucune règle n'existe, un Hero d'onboarding propose **Créer ma première règle** ou **Importer un pack**.
- Sinon, la page agrège profils épinglés, actions rapides, mini-statistiques et astuces.
- Le focus clavier est posé sur la première action ; les boutons d'actions rapides ont des raccourcis à une touche.
</Aside>

## Hero d'onboarding

Quand aucune règle n'est encore définie dans le workspace actif, le Hero d'onboarding occupe la partie haute. Deux actions :

- **Créer ma première règle** : ouvre directement l'assistant de création de règle.
- **Importer un pack** : ouvre la [galerie de packs](/reference/categories-et-packs) dans le wizard d'import.

Dès qu'une règle existe, le Hero d'onboarding disparait au profit des autres sections.

## Profils épinglés

Cette section regroupe jusqu'à 6 [sessions épinglées](/guides/sessions#sessions-epinglees) du workspace actif, triées par date de mise à jour décroissante. Chaque profil s'affiche sous forme de tuile cliquable, navigable au clavier (flèches gauche/droite).

Quatre raccourcis pilotent la restauration du profil qui a le focus :

| Raccourci | Cible | Comportement |
|---|---|---|
| `R` | Personnalisée | Ouvre le wizard de restauration et laisse choisir le mode. |
| `Shift + R` | Fenêtre actuelle | Ajoute les onglets à la fenêtre actuellement au premier plan. |
| `Alt + R` | Remplacer | Ferme les onglets actuels et restaure ceux du profil dans la même fenêtre. |
| `Alt + Shift + R` | Nouvelle fenêtre | Ouvre une nouvelle fenêtre dédiée et y restaure les onglets. |

Ces quatre cibles sont également exposées dans la popup. Voir [Sessions, profils popup](/guides/sessions#profils-dans-la-popup).

L'action déclenchée par un clic ou un appui sur `Enter` est configurable dans [Paramètres](/guides/parametres) (réglage **Action de restauration par défaut**).

## Actions rapides

Une grille d'actions usuelles, chacune accessible par un raccourci à une seule touche quand le focus est sur la page d'accueil :

| Raccourci | Action |
|---|---|
| `O` | Organiser tous les onglets selon les règles actives. |
| `S` | Capturer un instantané de la fenêtre courante. |
| `N` | Créer une nouvelle règle de domaine. |
| `I` | Aller à Import / Export. |
| `T` | Aller aux statistiques. |

Les flèches permettent de déplacer le focus entre les cartes ; `Home` et `End` vont aux extrêmes.

## Mini-statistiques

Trois compteurs synthétiques : **groupes créés**, **doublons fermés**, **sessions enregistrées**. Chaque compteur est cliquable et amène vers la page complète correspondante. La section n'apparait que si au moins un compteur est non nul.

## Astuces

Un carrousel léger d'astuces tournantes (mode Intelligent, raccourcis, sessions épinglées, packs). Sa visibilité peut être désactivée depuis [Paramètres](/guides/parametres).
