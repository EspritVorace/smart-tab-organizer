La page **Règles de domaine** rassemble toutes vos règles existantes. Chaque ligne couvre un domaine et indique son label, son mode de configuration, sa catégorie et son état (activée ou désactivée).

<ThemeImage
  lightSrc={rulesListLight}
  darkSrc={rulesListDark}
  alt="Liste des règles de domaine avec quatre entrées couvrant les différents modes de configuration."
/>

Depuis cette vue vous pouvez :

- **Réordonner** les règles par glisser-déposer pour ajuster leur priorité.
- **Activer ou désactiver** une règle individuellement via son toggle, sans la supprimer.
- **Ouvrir l'assistant** pour modifier une règle existante ou en créer une nouvelle.
- **Effectuer des actions en masse** sur une sélection (suppression, activation, export).
