La page **Sessions** rassemble vos instantanés enregistrés. Chaque session apparait sous forme de carte avec son nom, son temps relatif et un aperçu de ses groupes.

<ThemeImage
  lightSrc={sessionsListLight}
  darkSrc={sessionsListDark}
  alt="Liste des sessions affichant une session fraîchement créée avec ses groupes d'onglets."
/>

Depuis cette vue vous pouvez :

- **Restaurer** une session dans la fenêtre courante ou une nouvelle fenêtre.
- **Épingler** une session pour la rendre permanente et l'associer à une fenêtre dédiée.
- **Rechercher** dans les noms de session ou en profondeur, jusque dans les titres des onglets capturés.
- **Renommer**, **éditer** ou **supprimer** un instantané sans quitter la liste.

<Aside type="note">
La capture ci-dessus est extraite du parcours narratif `00-main-journey` du pipeline `e2e-doc-scenarios/`. Elle est régénérée à chaque exécution de `pnpm doc:scenarios` pour rester synchronisée avec l'UI.
</Aside>
