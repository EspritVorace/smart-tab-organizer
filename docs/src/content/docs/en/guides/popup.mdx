## What the popup contains

- **Session statistics**: number of grouped tabs and closed duplicates since the browser opened.
- **Grouping and deduplication toggles**: global switches with immediate effect on the entire extension. The off state is reflected by the badge on the icon (see [Interface tour](/decouverte/tour-interface#indicateur-sur-licone)).
- **Workspace switcher** (`PopupWorkspaceSwitcher`): change workspace without opening Options. See [Workspaces](/guides/workspaces#changer-de-workspace-actif).
- **Pinned profiles**: the list of [pinned sessions](/guides/sessions#sessions-epinglees) for the active workspace. Clicking a profile restores it with the configured default action; a context menu exposes the four targets.
- **Quick access buttons**: open the Rules, Sessions, and Settings pages in a new tab.

<Aside type="note">
The popup **never** loads archived sessions. Only the pinned and active sessions of the current workspace are projected there. For archived sessions, open the [Sessions](/guides/sessions#archive) page.
</Aside>

## Difference with the home page

The popup and the [home page](/decouverte/page-accueil) project the same list of pinned profiles, but with different space constraints:

- The **popup** shows profiles as a compact list with a context menu for the four restore targets.
- The **home page** shows profiles as wider tiles, with the `R` / `Shift+R` / `Alt+R` / `Alt+Shift+R` shortcuts wired directly to the focused tile.
