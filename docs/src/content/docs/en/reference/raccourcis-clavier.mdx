All keyboard shortcuts available in SmartTab Organizer, grouped by surface. Browser-wide shortcuts can be customized in your browser's extension settings.

## Home page

| Shortcut | Action |
| --- | --- |
| `←` or `→` | Move focus between cards |
| `Home` or `End` | Move focus to first or last item |
| `Tab` | Move focus to the next section |
| `Enter` | Activate the focused item |
| `O` | Organize all tabs |
| `S` | Save a snapshot of the current window |
| `N` | Create a new domain rule |
| `I` | Go to Import / Export |
| `T` | Go to statistics |

### Session card (focused)

| Shortcut | Action |
| --- | --- |
| `R` | Custom restore (wizard) |
| `Shift + R` | Add session to current window |
| `Alt + R` | Replace current window tabs |
| `Alt + Shift + R` | Open session in a new window |
| `U` | Refresh session from current window tabs |
| `→` | Expand the session's tab list |
| `←` | Collapse the session's tab list |
