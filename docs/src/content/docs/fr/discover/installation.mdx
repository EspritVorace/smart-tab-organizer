<Aside type="tip" title="En bref">
- Disponible sur le Chrome Web Store et sur Firefox Add-ons.
- Quatre permissions demandées, toutes locales (tabs, storage, notifications, scripting).
- Build local possible avec `pnpm install && pnpm build` (ou `pnpm build:firefox`).
</Aside>

## Installer depuis un store

<Tabs>
  <TabItem label="Chrome / Edge / Brave">
[SmartTab Organizer sur le Chrome Web Store](https://chromewebstore.google.com/detail/smarttab-organizer/ijnpdkkcbmfikocmboibffjgbohhlmah). Compatible avec tous les navigateurs basés sur Chromium (Chrome, Edge, Brave, Vivaldi, Arc, Opera).

<Steps>
1. Cliquez sur **Ajouter à Chrome**.
2. Validez les permissions demandées dans la boite de dialogue du navigateur.
3. Épinglez l'icône à la barre d'outils via le menu **Extensions** pour y accéder rapidement.
</Steps>
  </TabItem>
  <TabItem label="Firefox">
[SmartTab Organizer sur Firefox Add-ons](https://addons.mozilla.org/firefox/addon/smarttab-organizer/).

<Steps>
1. Cliquez sur **Ajouter à Firefox**.
2. Validez les permissions dans la boite de dialogue.
3. L'icône s'épingle automatiquement à la barre d'outils.
</Steps>
  </TabItem>
</Tabs>

## Permissions demandées

L'extension demande quatre permissions, toutes utilisées exclusivement en local. Aucune n'autorise une communication réseau.

| Permission | Pourquoi |
|---|---|
| `tabs` | Lire les URL et titres des onglets pour pouvoir les grouper et détecter les doublons. |
| `storage` | Persister vos règles, sessions et paramètres dans `browser.storage.local`. |
| `notifications` | Afficher les notifications de groupement et de déduplication, avec le bouton **Annuler**. |
| `scripting` | Injecter le content script qui capture les clics milieu et clics droits sur les liens, pour déclencher le groupement. |

<Aside type="caution">
L'extension ne demande **pas** `host permissions` étendues ni `webRequest`. Elle ne peut pas inspecter le trafic réseau et ne lit jamais le contenu des pages au-delà des liens cliqués.
</Aside>

## Installer en local depuis les sources

Pour développer ou tester une version non publiée :

<Tabs>
  <TabItem label="Chrome / Chromium">

```bash
git clone https://github.com/EspritVorace/smart-tab-organizer.git
cd smart-tab-organizer
pnpm install
pnpm build
```

<Steps>
1. Ouvrez `chrome://extensions` dans Chrome.
2. Activez le mode développeur en haut à droite.
3. Cliquez sur **Charger l'extension non empaquetée** et sélectionnez le dossier `.output/chrome-mv3/`.
</Steps>
  </TabItem>
  <TabItem label="Firefox">

```bash
git clone https://github.com/EspritVorace/smart-tab-organizer.git
cd smart-tab-organizer
pnpm install
pnpm build:firefox
```

<Steps>
1. Ouvrez `about:debugging#/runtime/this-firefox`.
2. Cliquez sur **Charger un module complémentaire temporaire**.
3. Sélectionnez le fichier `.output/firefox-mv2/manifest.json`.
</Steps>

<Aside type="note">
Une installation temporaire dans Firefox est perdue à la fermeture du navigateur. Pour un usage permanent depuis les sources, utilisez `pnpm zip:firefox` et signez le `.xpi`.
</Aside>
  </TabItem>
</Tabs>

## Premier lancement

Une fois l'extension installée :

<Steps>
1. Cliquez sur l'icône SmartTab Organizer dans la barre d'outils. La popup s'ouvre vide, sans règle ni session enregistrée.
2. Cliquez sur **Options** pour ouvrir la page complète. Si certains onglets ouverts correspondent à un pack prêt à l'emploi, l'onglet **Accueil** liste les packs correspondants (avec le nombre d'onglets concernés par pack) et un bouton **Importer et organiser**. Sinon, il propose deux actions génériques : **Créer ma première règle** ou **Importer un pack**.
3. L'analyse des packs est entièrement locale : les onglets ouverts sont lus dans le navigateur uniquement, rien ne quitte la machine. Les suggestions peuvent être ignorées pour conserver les actions génériques.
4. Après l'import, un bouton **Organiser maintenant** range immédiatement les onglets ouverts. Voir [Catégories et packs](/reference/categories-and-packs).
</Steps>
