SmartTab Organizer est une extension navigateur cross-browser (Chromium MV3 et Firefox MV2), entièrement écrite en TypeScript. Aucune partie de l'application ne dépend d'un serveur ou d'un service tiers : la totalité du code s'exécute dans le navigateur.

## Pile applicative

| Couche | Technologie |
|---|---|
| Build et packaging | [WXT](https://wxt.dev) (framework d'extensions multi-cibles) |
| UI | React 19, [Radix Themes](https://www.radix-ui.com/themes) et [Radix Primitives](https://www.radix-ui.com/primitives) |
| Types et validation | TypeScript strict, [Zod](https://zod.dev) pour les schémas runtime |
| Tests unitaires | [Vitest](https://vitest.dev) + Testing Library |
| Tests E2E | [Playwright](https://playwright.dev) (Chrome MV3) |
| Storybook | Storybook 8 + addon-a11y et test-runner avec axe-core |
| Documentation | [Astro Starlight](https://starlight.astro.build) (ce site) |
| Lint et format | ESLint, Prettier |

## Cible navigateurs

| Navigateur | Manifest | Statut |
|---|---|---|
| Chrome | MV3 | Cible principale |
| Edge, Brave, Vivaldi, Arc, Opera (basés Chromium) | MV3 | Compatible (même artefact que Chrome) |
| Firefox | MV2 | Compatible (cibles `pnpm build:firefox`, `pnpm zip:firefox`) |

Les API navigateur sont accédées via `wxt/browser`, qui normalise les différences entre `chrome.*` et `browser.*`. L'extension utilise un sous-ensemble qui existe sur les deux : `browser.tabs`, `browser.tabGroups`, `browser.storage`, `browser.action` / `browser.browserAction`, `browser.notifications`, `browser.scripting`.

## Stockage

| Backend | Contenu |
|---|---|
| `browser.storage.local` | Règles de domaine, paramètres, sessions (pinned, active, archived), workspaces, catégories, préférences UI (état déplié, etc.) |
| `browser.storage.session` | Carte profil-fenêtre, brouillons de session, garde anti-réentrance d'édition |

Aucun cookie. Aucune requête réseau autre que celles du navigateur lui-même.
