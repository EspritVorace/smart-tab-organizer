## Mes onglets ne sont pas regroupés, pourquoi ?

Trois conditions doivent être réunies pour qu'un groupe soit créé : le **toggle global Groupement** est activé, une **règle de domaine** correspond au domaine de l'onglet, et l'option **Groupement** est activée sur cette règle. Voir [Grouper les onglets, conditions](/guides/group-tabs#conditions-pour-quun-groupe-soit-cree).

Autre piste : seuls les onglets ouverts via **clic milieu** ou **clic droit puis Ouvrir dans un nouvel onglet** déclenchent le groupement. Les onglets ouverts depuis la barre d'adresse ou un raccourci clavier ne le font pas.

Vérifiez aussi la pastille sur l'icône : un **G** orange signale que le toggle global est désactivé.

## Quelle est la différence entre un pack et un preset ?

Un **pack** ajoute plusieurs règles d'un coup à votre workspace (galerie d'import). Un **preset** pré-remplit une seule règle, celle que vous êtes en train de créer dans le wizard. Voir [Catégories et packs](/reference/categories-and-packs) et [Presets regex](/reference/regex-presets).

## Pourquoi un onglet revient après une déduplication ?

Si vous avez cliqué sur **Annuler** dans la notification, l'onglet est volontairement rouvert et protégé pendant 10 secondes pour éviter qu'il soit refermé immédiatement. Voir [Dédupliquer, notification et annulation](/guides/deduplicate#undo).

Si vous n'avez pas annulé et que l'onglet réapparait, vérifiez que la stratégie de conservation correspond bien à ce que vous voulez : par défaut (**L'onglet groupé gagne, sinon le nouveau**), l'extension privilégie le tab fraîchement chargé sur le tab existant quand aucun des deux n'appartient à un groupe.

## Est-ce que mes données partent sur internet ?

Non. L'extension ne fait **aucune** requête réseau. Le groupement repose sur des expressions régulières exécutées localement, et toutes les données (règles, sessions, paramètres) vivent dans `browser.storage.local` du navigateur. Voir [Pourquoi cette extension](/discover/why#tout-est-local-rien-ne-part-en-ligne).

## Est-ce que mes règles et sessions se synchronisent entre appareils ?

Pas par l'extension elle-même. Mais si vous synchronisez votre profil Chrome ou Firefox (via Google ou Firefox Sync), `browser.storage.local` est inclus dans la synchronisation, donc vos règles et sessions vous suivent. L'extension reste compatible avec ce mécanisme natif sans le déclencher elle-même.

## Comment migrer mes règles d'un navigateur à l'autre ?

Exportez vos règles depuis le navigateur source (page Import / Export, bouton **Exporter**), puis importez le fichier JSON dans le navigateur cible. Pour une migration complète (règles + sessions + paramètres), exportez plutôt le **workspace** entier. Voir [Import / Export, workspaces](/guides/import-export#workspaces).

## Compatibilité avec Firefox

Oui, Firefox est supporté via une build MV2 dédiée (`pnpm build:firefox` en local, ou Firefox Add-ons pour l'installation publique). Les API utilisées sont communes aux deux plateformes. Voir [Installation](/discover/installation).

## Compatibilité avec Vivaldi

Partiellement. La déduplication, les sessions et l'extraction regex du nom fonctionnent, mais le groupage automatique reste sans effet : Vivaldi n'expose pas l'API de groupes d'onglets de Chromium et s'appuie sur ses propres Tab Stacks, non pilotables par une extension.

## L'extension peut-elle lire le contenu de mes pages ?

Non. Les permissions demandées sont `tabs`, `storage`, `notifications` et `scripting`. Le `scripting` est utilisé uniquement pour injecter un petit script qui capture les **clics** sur les liens (pour mémoriser le lien ciblé avant que l'onglet ne s'ouvre). Aucune lecture du DOM ni du contenu des pages.

## Comment réinitialiser l'extension complètement ?

Désinstaller puis réinstaller l'extension purge complètement `browser.storage.local`. Si vous voulez seulement vider les compteurs sans tout supprimer, utilisez le bouton **Réinitialiser** sur la page [Statistiques](/guides/statistics#reinitialiser-les-compteurs).

## Où signaler un bug ou suggérer une fonctionnalité ?

Sur le [tracker d'issues GitHub](https://github.com/EspritVorace/smart-tab-organizer/issues). Précisez le navigateur (Chrome / Edge / Firefox + version), une description du comportement attendu vs observé, et idéalement les étapes pour reproduire.

## Est-ce que l'extension utilise de l'IA ?

Non. Aucune IA, ni locale ni distante. Le nommage des groupes repose uniquement sur des expressions régulières exécutées dans votre navigateur (les vôtres, ou celles d'un pack intégré). Voir [Pourquoi cette extension](/discover/why#tout-est-local-rien-ne-part-en-ligne).

## Est-ce vraiment gratuit ? Quel est le modèle économique ?

Oui, gratuit et sans contrepartie : pas de version payante, pas de palier premium, pas de fonction bridée. L'extension est open source sous licence GPL v3, donc vérifiable et contribuable par tous. Voir la [page d'attribution open source](/reference/open-source-licenses).

## En quoi est-ce différent des groupes d'onglets natifs du navigateur ?

Les groupes natifs de Chrome se créent et se nomment à la main. SmartTab Organizer les crée automatiquement selon vos règles de domaine, ferme les doublons, et sauvegarde l'état de vos onglets sous forme de sessions restaurables. Il s'appuie sur les groupes natifs, il ne les remplace pas. Voir [Grouper les onglets](/guides/group-tabs).

## Est-ce que ça fonctionne hors ligne ?

Oui. L'extension n'a besoin d'aucune connexion : groupement, déduplication, sessions et statistiques tournent entièrement en local. La seule intervention du réseau, c'est lorsque vous ouvrez vous-même une page dans un onglet.
