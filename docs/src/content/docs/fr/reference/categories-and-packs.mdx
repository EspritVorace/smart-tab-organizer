<Aside type="tip" title="En bref">
- Un **pack** est un bundle de règles à importer d'un coup. SmartTab Organizer embarque 49 packs intégrés.
- Un **preset** est un modèle regex isolé, sélectionnable dans le wizard de création de règle. Voir [Presets regex](/reference/regex-presets).
- Une **catégorie** apporte un emoji et un libellé. 14 catégories sont définies, partagées entre tous les workspaces. Elles n'influent pas sur la couleur du groupe Chrome, qui est un champ indépendant de la règle.
</Aside>

## Pack, preset, catégorie

| Notion | Action | Où la rencontrer |
|---|---|---|
| **Pack** | Ajoute plusieurs règles d'un coup. | Galerie de packs (page Règles, Import / Export, Hero d'onboarding). |
| **Preset** | Pré-remplit la règle en cours d'édition. | Dropdown **Preset** dans le wizard de création de règle. |
| **Catégorie** | Donne un emoji et un libellé à une règle ou à une session. | Champ **Catégorie** dans le wizard de règle et dans l'éditeur de session. |

## Les 14 catégories

Les catégories sont **intégrées à l'extension** et définies dans `src/data/categories.json`. Elles ne se créent pas et ne se modifient pas depuis l'interface : vous les choisissez dans le champ **Catégorie** du wizard de règle ou de session.

| Emoji | Catégorie | Exemples de règles |
|---|---|---|
| 🔍 | Recherche | Moteurs de recherche, Wikipédia |
| 💬 | Communication | Slack, Discord, Visioconférences |
| 🎬 | Médias et Streaming | YouTube, Spotify, plateformes SVOD |
| 🗣️ | Réseaux sociaux | LinkedIn, X (Twitter), Reddit |
| 🛍️ | Commerce | Amazon, places de marché |
| 📰 | Actualités | Presse française et internationale |

| 🤖 | Assistants IA | ChatGPT, Claude, Gemini, Perplexity |
| ✈️ | Voyage | Vols, hôtels, billets de train |
| 💰 | Finance | Marchés, paiements, crypto, actions |

## Importer un pack

<Steps>
1. Ouvrez le wizard d'import depuis la page Règles, depuis Import / Export, ou depuis le Hero d'onboarding (bouton **Importer un pack** tant qu'aucune règle n'existe). Quand des onglets ouverts correspondent à un pack, le Hero suggère directement ces packs, pré-sélectionnés.
2. Sélectionnez l'onglet **Packs intégrés**.
3. Parcourez la galerie par catégorie (barre latérale gauche) ou via la recherche (insensible aux accents : `videoconference` trouve **Visioconférences**). Les packs qui correspondent à vos onglets ouverts remontent en tête et portent une étiquette **Correspond à vos onglets** ; la recherche et les filtres par catégorie restent prioritaires.
4. Cliquez sur un pack pour voir son détail. Cochez les packs à importer (sélection multiple supportée).
5. Si le pack est **configurable** (par exemple **Console AWS** propose un sélecteur **Service AWS**), choisissez le paramètre avant de valider.
6. Confirmez. Les règles du pack sont ajoutées au workspace actif.
</Steps>

### Packs configurables

Certains packs (typiquement les packs cloud) proposent un paramètre à choisir avant l'import. Le service sélectionné devient la règle mise en avant à l'import ; les autres règles du pack sont aussi ajoutées, mais le pack est marqué comme spécialisé sur le service choisi.

Vous pouvez réimporter un pack plusieurs fois avec des paramètres différents : les règles déjà présentes seront détectées comme conflits par le wizard d'import et résolues au cas par cas (voir [Import / Export](/guides/import-export#resolution-propriete-par-propriete)).

## Catalogue complet

La liste exhaustive des 49 packs n'est volontairement pas reproduite dans cette documentation : elle évolue avec les versions et risque de se désynchroniser. La source de vérité est la galerie de packs elle-même, parcourable dans l'extension. Les manifestes sont versionnés dans [`src/data/packs/`](https://github.com/EspritVorace/smart-tab-organizer/tree/main/src/data/packs) pour qui veut inspecter ou contribuer.
